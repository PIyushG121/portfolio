# Portfolio Logo Pack

Canonical technology/brand SVG set prepared for `PIyushG121/portfolio`.

## Primary sources

Most icons are sourced from Simple Icons (current CDN / current Simple Icons catalog) and saved with the filenames already used by the portfolio:

- https://simpleicons.org/
- https://github.com/simple-icons/simple-icons
- CDN pattern: https://cdn.simpleicons.org/<slug>/<hex-color>

Simple Icons is CC0-1.0. Individual brand names/logos remain trademarks of their respective owners.

## Recommended replacement

Copy these files into:

`public/assets/img/assets_logo/`

They intentionally use the stable filenames referenced by `resources/views/home.blade.php`, so no code changes are required for the main technology/skill icon references.

## Important

Do not treat `aiml.svg` as the official logo of a particular AI company. It is a semantic UI icon because “AI/ML” is a category rather than one brand.
